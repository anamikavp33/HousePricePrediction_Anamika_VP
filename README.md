# HousePricePrediction_Anamika_VP
# House Price Prediction Using Machine Learning

## XYlofy AI Internship - Week 1 Project

### Objective
Predict house prices using machine learning models and analyze factors affecting house prices.

### Dataset
Housing Prices Dataset (545 records)

### Models Used
- Linear Regression
- Random Forest Regressor

### Results
Linear Regression:
- MAE: 970,043
- RMSE: 1,324,507
- R² Score: 0.653

Random Forest:
- MAE: 1,022,560
- RMSE: 1,401,497
- R² Score: 0.611

### Key Findings
House area was the most influential feature affecting house prices.
